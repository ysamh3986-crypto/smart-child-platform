# أكاديمية الطفل الذكي — Telegram Mini App
واجهة الأكاديمية تفتح داخل تطبيق Telegram عبر Web App، والبوت يقدم زر الفتح والتنقل.
## النشر
- انشر مجلد `telegram` كـ Static Site مع HTTPS، وPublish Directory = `telegram`.
- أنشئ بوتاً عبر @BotFather بالأمر /newbot.
- شغّل `bot.py` بخدمة Python وضع متغيري البيئة `BOT_TOKEN` و`WEBAPP_URL`.
- من BotFather عيّن زر القائمة عبر /setmenubutton وأدخل رابط HTTPS.
## ملاحظة مهمة
هذه نسخة أولية: الألعاب والدرس والاختبار والشهادة تعمل محلياً، والنجوم محفوظة على جهاز الطفل. لم تُفعّل بعد حسابات الطلاب أو حفظ النتائج في قاعدة البيانات أو لوحة المعلمة. لا تضع توكن البوت في GitHub أو ترسله في رسالة عامة. يلزم التحقق من Telegram initData في الخادم قبل ربط الحسابات والنتائج.
